# 机器人外观

供应商编辑页的“显示机器人”只替换刘海圆环中央图标，并提供性格、形状、颜色和实时预览。列表、详情和菜单仍显示供应商图标。Code Switch R 行与本地模型账户行通过“外观”按钮编辑同样的设置。

外观保存到 `Preferences.botAppearances`，普通供应商按条目 ID、联动供应商按现有平台与供应商组合 ID 保存。本地模型继承 `sourceProviderID` 的外观。关闭机器人保留外观与原图标；同步数据不覆盖本地选择。自动性格和非品牌色使用稳定哈希，不依赖显示排序。

## 动画与生命周期

窗口共享一个上限 60 Hz 的显示链接；帧更新只进入 AppKit 绘制视图，不发布 SwiftUI 状态。折叠、移出可见区域、遮挡、休眠和关闭预览时停止更新，窗口没有活动机器人时释放显示链接。减少动态效果使用有界缓存中的静态姿态。

机器人使用实际活动、刷新和额度状态。等待用户显示倾听，工作优先于刷新；完成与额度重置使用去重事件，隐藏期间不积压待播放事件。供应商无读数时休眠。保留原来的独立刷新短弧与活动指示。

安静待机从共享会话活动时间判断，所有 CLI 的活动都会更新基线；未知活动不视为安静，存在工作会话时不进入安静状态。会话消失后保留已观测时间，重建预览、折叠或新建窗口不重新计时。该时间使用本项目会话监控提供的状态时间，不额外扫描 CLI 日志。

Code Switch R 的手动读取和上游 `loading` 均进入刷新状态，后台定时与文件变动轮询不会单独触发刷新动作；刷新状态在读取完成或关闭联动时清除。会话绑定条目保留来源供应商的加载状态。额度耗尽判断使用原始额度窗口，不把 Daily Pace 合成比例超标视为真实额度耗尽。通知静音不关闭额度重置庆祝，恢复通知后也不补播旧事件。

可见性检查使用视图边界与可见区域的交集，并监听祖先几何变化及隐藏恢复，因此时钟停止后也能由滚动或重新显示唤醒。渐变绘制复用 RGB 色彩空间，不为持续变化的粒子颜色建立无限缓存。

视线随胶囊贴边方向调整：左侧看右、右侧看左，顶部和底部以正面为主并保留小幅瞥视。方向改变通过弹簧平滑过渡，只移动眼睛，不镜像身体；横纵布局切换保留绘制实例。鼠标位于胶囊实际轮廓内时优先跟随，移出后平滑恢复；设置预览只在自身区域内跟随。减少动态效果直接展示目标方向，静态缓存区分朝向。

鼠标接管时，自主朝向、自然漂移和脸部横向偏移平滑退至零，避免中心附近的小幅鼠标移动仍被默认朝向压过。鼠标离开后恢复原有活动。胶囊命中路径按边缘、几何区域、缩放和硬件刘海状态缓存，同一窗口的供应商共用路径，活动更新不重复构造路径。

表情眼形的中心偏移、动作和自主瞥视统一受限。眼睛按当前身体及形变轮廓收拢，徽标避让后再次校验；仅靠近边缘时执行实际路径检查，避免凹轮廓的预采样误差导致缺眼。眼睛在形变中本来不可见时跳过眼形计算。

两眼同时可见时保留至少 3 个内部坐标单位的水平间距。空间不足时以双眼整体调整位置和比例，并再次验证实际脸部轮廓，避免单眼独立收拢造成重叠。普通帧只计算包围盒，发生间距不足时才分配校正用轮廓数据。

## 验证边界

2026-09-18 使用本机 Swift 命令行工具将真实引擎源码独立编译为优化构建，验证 18 种形状与 5 类状态的 90 种组合、完整动作目录、配置未知值回退、事件结束和暂停恢复。600 个模拟帧、7 个机器人同时计算时，单帧引擎耗时 P95：待机约 0.016ms、工作约 0.079ms、庆祝约 0.178ms。这些数字不包含窗口合成和实际显示时钟，不能作为整应用 60 帧或 CPU 占用达标的证明。

`Tests/BotMarkTests.swift` 覆盖持久化、平台隔离、模型配置继承、多窗口配置传递、动作资源和生命周期。完整测试需要 Xcode 与 XCTest；本次环境只有 Command Line Tools，未运行完整应用构建和测试套件。

另已运行实际 AppKit 绘制视图的离屏验证，覆盖全部形状、暂停后帧计数不增长以及减少动态效果的停帧条件，并检查输出图片。图形会话注册在沙盒内失败，临时验证程序获准在沙盒外运行后通过；没有启动或修改已安装的应用。

2026-09-18 评审修复后，使用真实绘制视图和原生滚动视图验证滚出停帧、滚回恢复、自身与祖先隐藏恢复，恢复不依赖手动调用时钟更新；窗口可见属性由临时测试窗口固定提供，未替代整应用 UI 验证。另独立编译真实 Bridge、Reader 和 ResetWatcher 源码，使用临时合成快照及外围模型替身验证后台与手动刷新重叠、完成清理、禁用清理、静音重置去重及取消静音不补播。项目回归测试补充 Daily Pace、共享活动与新窗口继承、上游加载状态及会话绑定保留；完整 XCTest 仍待 Xcode 环境执行。

具备 Xcode 后运行 `make test`，并在同一设备和窗口布局下比较原图标与 1／7 个机器人，覆盖待机、工作、庆祝、指针互动、多屏、隐藏恢复及减少动态效果。记录帧间隔、CPU 和内存，检查隐藏后机器人帧计数不再增长。

视线改进的独立运行检查覆盖 18 种形状 × 25 种表情 × 3 个方向及鼠标接管，约 1,058 万个可见眼形顶点未越出脸部；另覆盖全部动作状态的转向与形变。AppKit 检查通过胶囊路径命中、透明角落排除、预览范围、静态方向缓存和隐藏恢复，并检查全部形状的三方向小尺寸图。项目测试同步补充四边映射、连续转向、表情与动作边界、指针优先及静态缓存。

同机优化构建、40pt 画布的引擎加离屏绘制抽样中，7 个机器人待机／工作／额度耗尽的每帧 P95 分别约 0.59／0.62／0.11ms。动作含随机选择，这些数据用于检查明显退化，不代表严格可重复的前后提升比例，也不包括实际窗口合成和显示帧率；完整应用构建和 XCTest 仍需 Xcode。

鼠标接管与双眼间距修复后，独立程序验证全部形状与三方向下的 ±0.05、±0.005、中心位置、穿过中心和移出恢复；表情与动作组合分别检查约 1,064 万／1,334 万个眼形顶点，同时断言双眼间距，未发现越界或重叠。胶囊命中、预览范围、静态方向缓存及隐藏恢复再次通过；命中路径复用与布局失效已加入项目测试，待完整 XCTest 环境执行。7 个机器人离屏绘制抽样 P95：待机约 0.58ms、工作约 0.98ms、额度耗尽约 0.11ms，随机动作样本不用于声称精确的性能提升比例。
